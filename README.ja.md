# SwiftRichTextEditor

[English](README.md) | **日本語**

SwiftUI のためのリッチテキストエディタです。1行で配置でき、ほかの SwiftUI
ビューと同じ流儀でカスタマイズできる、標準的な選択肢になることを目指しています。

> [!WARNING]
> **ステータス：開発初期段階です。** まだ利用できるものはありません。以下に示す
> API は設計上の目標であり、動作するコードの説明ではありません。進捗を追うには、
> リポジトリを Star または Watch してください。

## なぜ作るのか

SwiftUI 標準の `TextEditor` は、新しい OS では文字単位の装飾に対応しています。
しかし実際のエディタには、太字や斜体以上のものが必要です。リスト、リンク、
添付ファイル、保存や交換ができるドキュメント形式を必要とするアプリは、いまでも
UIKit や AppKit を自前でラップしています。

SwiftRichTextEditor はその隙間を埋めます。

## 目標

- **1行で導入できる。** ビューを1つ置くだけで、実用的なツールバー付きの
  エディタが動きます。UIKit や AppKit の知識は要りません。
- **SwiftUI らしくカスタマイズできる。** スタイル、ツールバー、挙動は、
  ビュー修飾子と Environment で設定します。
- **ブロック単位の編集ができる。** 太字、斜体、下線、リンクといった
  インラインの装飾に加えて、見出し、リスト、引用を扱えます。
- **UI に依存しないドキュメントモデルを持つ。** モデルはビューなしでテストでき、
  `AttributedString`、Markdown、HTML と相互に変換できます。
- **どの言語でも正しく入力できる。** 変換を伴う入力方式（日本語、中国語、
  韓国語）への対応は、後付けではなく最初からの要件です。
- **アクセシビリティに対応する。** VoiceOver と Dynamic Type が、追加の設定なしで
  動作します。

## 目標としないこと

- コードエディタ。シンタックスハイライトや言語ツールは対象外です。
- Web ベースの WYSIWYG エディタ。エディタはネイティブ実装で、Web ビューを
  埋め込みません。
- リアルタイムの共同編集。

## 想定している使い方

以下は、このプロジェクトが目指している API です。まだ実装されておらず、
今後変更されます。

```swift
import SwiftUI
import SwiftRichTextEditor

struct NoteView: View {
    @State private var document = RichTextDocument()

    var body: some View {
        RichTextEditor(document: $document)
    }
}
```

## 動作要件

- iOS 17 以降 / macOS 14 以降
- Swift 6.4 以降

## インストール

最初のバージョンがタグ付けされたら、Swift Package Manager で追加できます。

```swift
dependencies: [
    .package(url: "https://github.com/Ryota-Kurokawa/swift-rich-text-editor.git", from: "0.1.0"),
]
```

まだリリースされたバージョンはありません。

## ロードマップ

1. **技術検証** — 編集エンジンを選定し、選択範囲の同期と、変換を伴う入力を
   プロトタイプで実証します。
2. **MVP** — 太字、斜体、下線、リスト、リンク、標準ツールバー、サンプルアプリ。
3. **0.1.0** — 最初のタグ付きリリース。DocC ドキュメントを含みます。
4. **その後** — 添付ファイル、メンション、Markdown と HTML の変換。
